Sequences and Series — Answer Key

MSBSHSE Std XI Mathematics Part I · Full Solutions with Working

Note for Educators: Full worked solutions are provided below. Students should be encouraged to attempt the test independently before reviewing these solutions for self-assessment and learning.
Section A — Sequence, Series & A.P. (2 marks each)
A1 Definition
Define a sequence and a series. State the general term formula for an A.P.
Answer:
A sequence is a function whose domain is the set of natural numbers; each output is a term $t_n$.
A series is the sum of the terms of a sequence: $S_n = t_1 + t_2 + \cdots + t_n$
General term of A.P.: $t_n = a + (n-1)d$, where $a$ is the first term and $d$ is the common difference.
A2 A.P. — nth Term
Find the 12th term of the A.P.: $5, 9, 13, 17, \ldots$
Given: $a = 5$, $d = 9 - 5 = 4$, $n = 12$
Using $t_n = a + (n-1)d$:
$t_{12} = 5 + (12-1) \times 4 = 5 + 11 \times 4 = 5 + 44 = 49$
$t_{12} = 49$
A3 A.P. — Sum Formula
Find the sum of the first 30 terms of the A.P. whose first term is $4$ and common difference is $5$.
Given: $a = 4$, $d = 5$, $n = 30$
Using $S_n = \dfrac{n}{2}[2a + (n-1)d]$:
$S_{30} = \dfrac{30}{2}[2(4) + (30-1) \times 5]$
$= 15[8 + 29 \times 5]$
$= 15[8 + 145]$
$= 15 \times 153 = 2295$
$S_{30} = 2295$
A4 A.P. — Finding $a$ and $d$
If the 7th term of an A.P. is $34$ and the 13th term is $64$, find the first term and common difference.
Given: $t_7 = 34$, $t_{13} = 64$
Using $t_n = a + (n-1)d$:
$t_7 = a + 6d = 34$ ... (1)
$t_{13} = a + 12d = 64$ ... (2)
Subtracting (1) from (2): $(a + 12d) - (a + 6d) = 64 - 34$
$6d = 30 \Rightarrow d = 5$
From (1): $a + 6(5) = 34 \Rightarrow a + 30 = 34 \Rightarrow a = 4$
$a = 4$, $d = 5$
A5 A.P. — Solving for $n$
How many terms of the A.P. $2, 5, 8, 11, \ldots$ add up to $155$?
Given: $a = 2$, $d = 3$, $S_n = 155$
Using $S_n = \dfrac{n}{2}[2a + (n-1)d]$:
$155 = \dfrac{n}{2}[2(2) + (n-1)(3)]$
$155 = \dfrac{n}{2}[4 + 3n - 3]$
$155 = \dfrac{n}{2}[1 + 3n]$
$310 = n(1 + 3n) = n + 3n^2$
$3n^2 + n - 310 = 0$
Using the quadratic formula: $n = \dfrac{-1 \pm \sqrt{1 + 4(3)(310)}}{2(3)} = \dfrac{-1 \pm \sqrt{3721}}{6} = \dfrac{-1 \pm 61}{6}$
$n = \dfrac{60}{6} = 10$ (taking positive value)
$n = 10$
Section B — Geometric Progression (2 marks each)
B1 G.P. — nth Term
Find the 9th term of the G.P.: $4, 8, 16, 32, \ldots$
Given: $a = 4$, $r = \dfrac{8}{4} = 2$, $n = 9$
Using $t_n = ar^{n-1}$:
$t_9 = 4 \times 2^{9-1} = 4 \times 2^8 = 4 \times 256 = 1024$
$t_9 = 1024$
B2 G.P. — Sum of $n$ Terms
Find the sum of the first 8 terms of the G.P.: $3, 9, 27, \ldots$
Given: $a = 3$, $r = 3$, $n = 8$
Using $S_n = \dfrac{a(r^n - 1)}{r - 1}$ (since $r > 1$):
$S_8 = \dfrac{3(3^8 - 1)}{3 - 1} = \dfrac{3(6561 - 1)}{2} = \dfrac{3 \times 6560}{2} = \dfrac{19680}{2} = 9840$
$S_8 = 9840$
B3 G.P. — Sum to Infinity
State the condition under which the sum to infinity of a G.P. exists, and write the formula.
Condition: The sum to infinity of a G.P. exists when $|r| < 1$ (i.e., the common ratio is less than 1 in absolute value).
Formula: $S_\infty = \dfrac{a}{1 - r}$, where $a$ is the first term and $|r| < 1$.
B4 G.P. — Sum to Infinity (Calculation)
Find $S_\infty$ for the G.P.: $12, 4, \dfrac{4}{3}, \dfrac{4}{9}, \ldots$
Given: $a = 12$, $r = \dfrac{4}{12} = \dfrac{1}{3}$
Since $|r| = \dfrac{1}{3} < 1$, sum to infinity exists.
Using $S_\infty = \dfrac{a}{1 - r}$:
$S_\infty = \dfrac{12}{1 - \frac{1}{3}} = \dfrac{12}{\frac{2}{3}} = 12 \times \dfrac{3}{2} = 18$
$S_\infty = 18$
B5 G.P. — Finding Terms
The 4th term of a G.P. is $24$ and the 7th term is $192$. Find the G.P.
Given: $t_4 = 24$, $t_7 = 192$
Using $t_n = ar^{n-1}$:
$t_4 = ar^3 = 24$ ... (1)
$t_7 = ar^6 = 192$ ... (2)
Dividing (2) by (1): $\dfrac{ar^6}{ar^3} = \dfrac{192}{24}$
$r^3 = 8 \Rightarrow r = 2$
From (1): $a(2)^3 = 24 \Rightarrow 8a = 24 \Rightarrow a = 3$
G.P.: $3, 6, 12, 24, 48, \ldots$
G.P. is: $3, 6, 12, 24, 48, \ldots$
Section C — Harmonic Progression & Means (2 marks each)
C1 Harmonic Progression
Define a Harmonic Progression. If the 3rd and 6th terms of an H.P. correspond to $\dfrac{1}{9}$ and $\dfrac{1}{18}$ in the associated A.P., find the H.P.'s first three terms.
Definition: A Harmonic Progression is a sequence whose reciprocals form an Arithmetic Progression.
Solution: For the associated A.P.: $t_3 = \dfrac{1}{9}$, $t_6 = \dfrac{1}{18}$
Common difference: $d = \dfrac{t_6 - t_3}{6 - 3} = \dfrac{\frac{1}{18} - \frac{1}{9}}{3} = \dfrac{\frac{1-2}{18}}{3} = \dfrac{-\frac{1}{18}}{3} = -\dfrac{1}{54}$
First term of A.P.: $a = t_3 - 2d = \dfrac{1}{9} - 2(-\dfrac{1}{54}) = \dfrac{1}{9} + \dfrac{1}{27} = \dfrac{3+1}{27} = \dfrac{4}{27}$
First three terms of A.P.: $\dfrac{4}{27}, \dfrac{4}{27} - \dfrac{1}{54} = \dfrac{7}{54}, \dfrac{7}{54} - \dfrac{1}{54} = \dfrac{6}{54} = \dfrac{1}{9}$
H.P. (reciprocals of A.P.): $\dfrac{27}{4}, \dfrac{54}{7}, 9$
H.P. first three terms: $\dfrac{27}{4}, \dfrac{54}{7}, 9$
C2 A.M. & G.M.
Find the Arithmetic Mean and Geometric Mean of $9$ and $25$.
Arithmetic Mean: $A.M. = \dfrac{9 + 25}{2} = \dfrac{34}{2} = 17$
Geometric Mean: $G.M. = \sqrt{9 \times 25} = \sqrt{225} = 15$
A.M. = 17, G.M. = 15
C3 Harmonic Mean
Find the Harmonic Mean of $6$ and $10$.
Using $H.M. = \dfrac{2ab}{a + b}$:
$H.M. = \dfrac{2 \times 6 \times 10}{6 + 10} = \dfrac{120}{16} = \dfrac{15}{2} = 7.5$
H.M. = 7.5
C4 Relation Among Means
State the relation connecting A.M., G.M. and H.M. of two positive numbers, and verify it for the numbers $4$ and $16$.
Relation: $(G.M.)^2 = A.M. \times H.M.$
Verification for 4 and 16:
$A.M. = \dfrac{4 + 16}{2} = \dfrac{20}{2} = 10$
$G.M. = \sqrt{4 \times 16} = \sqrt{64} = 8$
$H.M. = \dfrac{2 \times 4 \times 16}{4 + 16} = \dfrac{128}{20} = 6.4$
Check: $(G.M.)^2 = 8^2 = 64$ and $A.M. \times H.M. = 10 \times 6.4 = 64$ ✓
Relation verified: $(G.M.)^2 = A.M. \times H.M.$
Section D — Arithmetico-Geometric Series (3 marks each)
D1 A.G.P. — First Terms
Write the first four terms of an A.G.P. whose associated A.P. has first term $2$, common difference $3$, and associated G.P. has first term $1$, common ratio $\dfrac{1}{2}$.
A.P. terms: $2, 5, 8, 11$
G.P. terms: $1, \dfrac{1}{2}, \dfrac{1}{4}, \dfrac{1}{8}$
A.G.P. terms (product pairwise):
$t_1 = 2 \times 1 = 2$
$t_2 = 5 \times \dfrac{1}{2} = \dfrac{5}{2}$
$t_3 = 8 \times \dfrac{1}{4} = 2$
$t_4 = 11 \times \dfrac{1}{8} = \dfrac{11}{8}$
A.G.P.: $2, \dfrac{5}{2}, 2, \dfrac{11}{8}$
D2 A.G.P. — Sum Formula
Find the sum to $n$ terms of the series: $1 + 3x + 5x^2 + 7x^3 + \cdots$ (where $x \neq 1$).
This is an A.G.P. with A.P.: $1, 3, 5, 7, \ldots$ and G.P.: $1, x, x^2, x^3, \ldots$
Let $S = 1 + 3x + 5x^2 + 7x^3 + \cdots + (2n-1)x^{n-1}$
Multiply by $x$: $xS = x + 3x^2 + 5x^3 + \cdots + (2n-1)x^n$
Subtract: $S - xS = 1 + 2x + 2x^2 + 2x^3 + \cdots + 2x^{n-1} - (2n-1)x^n$
$(1-x)S = 1 + 2(x + x^2 + \cdots + x^{n-1}) - (2n-1)x^n$
$(1-x)S = 1 + 2 \cdot \dfrac{x(1-x^{n-1})}{1-x} - (2n-1)x^n$
$S = \dfrac{1}{1-x} + \dfrac{2x(1-x^{n-1})}{(1-x)^2} - \dfrac{(2n-1)x^n}{1-x}$
$S_n = \dfrac{1 + 2x(1-x^{n-1})/(1-x) - (2n-1)x^n}{1-x}$
Section E — Sigma Notation & Special Series (3 marks each)
E1 Standard Formulas
State the standard formulas for $\sum_{k=1}^n k$, $\sum_{k=1}^n k^2$, and $\sum_{k=1}^n k^3$.
$\displaystyle\sum_{k=1}^n k = \dfrac{n(n+1)}{2}$
$\displaystyle\sum_{k=1}^n k^2 = \dfrac{n(n+1)(2n+1)}{6}$
$\displaystyle\sum_{k=1}^n k^3 = \left[\dfrac{n(n+1)}{2}\right]^2$
E2 Sum of Squares
Find $\sum_{k=1}^{25} k^2$.
Using $\sum_{k=1}^n k^2 = \dfrac{n(n+1)(2n+1)}{6}$ with $n = 25$:
$\sum_{k=1}^{25} k^2 = \dfrac{25 \times 26 \times 51}{6}$
$= \dfrac{25 \times 26 \times 51}{6} = \dfrac{33150}{6} = 5525$
$\sum_{k=1}^{25} k^2 = 5525$
E3 Sum of Cubes
Find $\sum_{k=1}^{12} k^3$.
Using $\sum_{k=1}^n k^3 = \left[\dfrac{n(n+1)}{2}\right]^2$ with $n = 12$:
$\sum_{k=1}^{12} k^3 = \left[\dfrac{12 \times 13}{2}\right]^2 = [6 \times 13]^2 = 78^2 = 6084$
$\sum_{k=1}^{12} k^3 = 6084$
E4 Special Series
Find the sum to $n$ terms of the series: $1 \cdot 2 + 2 \cdot 3 + 3 \cdot 4 + \cdots + n(n+1)$.
General term: $t_k = k(k+1) = k^2 + k$
$S_n = \sum_{k=1}^n k(k+1) = \sum_{k=1}^n (k^2 + k) = \sum_{k=1}^n k^2 + \sum_{k=1}^n k$
$= \dfrac{n(n+1)(2n+1)}{6} + \dfrac{n(n+1)}{2}$
$= \dfrac{n(n+1)}{6}[(2n+1) + 3]$
$= \dfrac{n(n+1)(2n+4)}{6} = \dfrac{n(n+1) \cdot 2(n+2)}{6}$
$= \dfrac{n(n+1)(n+2)}{3}$
$S_n = \dfrac{n(n+1)(n+2)}{3}$
E5 General Term Method
Find the sum to $n$ terms of the series whose general term is $t_n = n^2 + 2n$. Hence find the sum of the first 10 terms.
$S_n = \sum_{k=1}^n (k^2 + 2k) = \sum_{k=1}^n k^2 + 2\sum_{k=1}^n k$
$= \dfrac{n(n+1)(2n+1)}{6} + 2 \cdot \dfrac{n(n+1)}{2}$
$= \dfrac{n(n+1)(2n+1)}{6} + n(n+1)$
$= \dfrac{n(n+1)[(2n+1) + 6]}{6}$
$= \dfrac{n(n+1)(2n+7)}{6}$
For $n = 10$: $S_{10} = \dfrac{10 \times 11 \times 27}{6} = \dfrac{2970}{6} = 495$
$S_n = \dfrac{n(n+1)(2n+7)}{6}$; $S_{10} = 495$
Section F — HOTS / Mixed Applications (4 marks each)
F1 Prove That — G.P. Property
If $p, q, r, s$ are in G.P., prove that $(p+q), (q+r), (r+s)$ are also in G.P.
Given: $p, q, r, s$ are in G.P.
Let: $q = pk$, $r = pk^2$, $s = pk^3$ (where $k$ is the common ratio)
$p + q = p + pk = p(1 + k)$
$q + r = pk + pk^2 = pk(1 + k)$
$r + s = pk^2 + pk^3 = pk^2(1 + k)$
Common ratio: $\dfrac{q+r}{p+q} = \dfrac{pk(1+k)}{p(1+k)} = k$
$\dfrac{r+s}{q+r} = \dfrac{pk^2(1+k)}{pk(1+k)} = k$
Since consecutive terms have the same ratio $k$, $(p+q), (q+r), (r+s)$ are in G.P. Hence Proved
F2 Mixed Series Application
Find $n$ if: $\dfrac{1 \cdot 2 + 2 \cdot 3 + 3 \cdot 4 + \cdots n \text{ terms}}{1 + 2 + 3 + \cdots + n \text{ terms}} = \dfrac{100}{3}$.
Numerator: $\sum_{k=1}^n k(k+1) = \dfrac{n(n+1)(n+2)}{3}$ (from E4)
Denominator: $\sum_{k=1}^n k = \dfrac{n(n+1)}{2}$
Ratio: $\dfrac{\frac{n(n+1)(n+2)}{3}}{\frac{n(n+1)}{2}} = \dfrac{n(n+1)(n+2)}{3} \times \dfrac{2}{n(n+1)} = \dfrac{2(n+2)}{3}$
Given: $\dfrac{2(n+2)}{3} = \dfrac{100}{3}$
$2(n+2) = 100 \Rightarrow n + 2 = 50 \Rightarrow n = 48$
$n = 48$
F3 A.P. Application
The sum of three numbers in A.P. is $24$ and their product is $440$. Find the numbers.
Let the three numbers be: $a-d$, $a$, $a+d$
From sum: $(a-d) + a + (a+d) = 24 \Rightarrow 3a = 24 \Rightarrow a = 8$
From product: $(a-d) \cdot a \cdot (a+d) = 440$
$a(a^2 - d^2) = 440$
$8(64 - d^2) = 440$
$64 - d^2 = 55 \Rightarrow d^2 = 9 \Rightarrow d = \pm 3$
If $d = 3$: numbers are $5, 8, 11$
If $d = -3$: numbers are $11, 8, 5$ (same numbers)
The three numbers are: $5, 8, 11$
F4 Inserting Means
Insert 4 arithmetic means between $3$ and $33$.
Total number of terms: First term + 4 means + Last term = 6 terms
First term: $a = 3$, Last term: $l = 33$, Number of terms: $n = 6$
Using $l = a + (n-1)d$:
$33 = 3 + (6-1)d \Rightarrow 33 = 3 + 5d \Rightarrow 5d = 30 \Rightarrow d = 6$
The A.P. is: $3, 9, 15, 21, 27, 33$
The 4 arithmetic means are: $9, 15, 21, 27$
Means: $9, 15, 21, 27$
F5 Series from S(n)
If the sum of the first $n$ terms of a series is given by $S_n = 3n^2 + 2n$, find the $n$th term $t_n$. Identify what type of progression this series is.
For $n \geq 2$: $t_n = S_n - S_{n-1}$
$S_n = 3n^2 + 2n$
$S_{n-1} = 3(n-1)^2 + 2(n-1) = 3(n^2 - 2n + 1) + 2n - 2$
$= 3n^2 - 6n + 3 + 2n - 2 = 3n^2 - 4n + 1$
$t_n = (3n^2 + 2n) - (3n^2 - 4n + 1) = 6n - 1$
First term: $t_1 = S_1 = 3(1)^2 + 2(1) = 5$ (or $t_1 = 6(1) - 1 = 5$ ✓)
Common difference: $t_2 - t_1 = 11 - 5 = 6$ or $d = 6$ (coefficient of $n$ in $t_n = 6n - 1$)
Since $t_n = 6n - 1$ is linear in $n$, the series is an Arithmetic Progression with $a = 5$ and $d = 6$.
$t_n = 6n - 1$; Series is A.P. with $a = 5$, $d = 6$
